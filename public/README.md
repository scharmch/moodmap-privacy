# MoodMap AI — Static Pages

Host these files on GitHub Pages:
1. Create a repo called `moodmap-privacy` on GitHub
2. Upload the contents of this `public/` folder
3. Go to Settings → Pages → Source → main branch → Save
4. Your URLs will be:
   - https://scharmch.github.io/moodmap-privacy/privacy.html
   - https://scharmch.github.io/moodmap-privacy/support.html
